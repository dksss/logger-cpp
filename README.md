# Logger cpp

Библиотека для записи сообщений в журнал с разными уровнями важности и приложение, демонстрирующее работу библиотеки.

## Возможности библиотеки

- **Динамическая библиотека** (`liblogger.so`), реализованная на C++17.
- Инициализация с параметрами:
  - Имя файла журнала.
  - Уровень важности сообщений по умолчанию (три уровня: INFO, WARNING, ERROR).
- Запись логов с сохранением:
  - Текста сообщения.
  - Уровня важности.
  - Времени получения сообщения.
- Возможность динамического изменения минимального уровня важности после инициализации.
- Использование только стандартной библиотеки C++ без сторонних зависимостей.


## Возможности консольного приложения

- Подключение и использование библиотеки для записи сообщений.
- Приём сообщений и уровней важности от пользователя через консоль.
- Потокобезопасная передача сообщений в отдельный поток записи.
- Параметры запуска:
  - Имя файла журнала.
  - Уровень важности по умолчанию.
- Реализация на C++17 с использованием механизмов многопоточности и ООП.
- Обработка ошибок.


## Запуск приложения

```
./build/app <путь_к_журналу> <уровень_важности>
```
- `<путь_к_журналу>` — путь к файлу лога, например, `mylog.txt`.
- `<уровень_важности>` — один из `INFO`, `WARNING`, `ERROR`.

Пример: `./build/app logs.txt info`


## Цели Makefile

* `all / app` - собрать библиотеку и приложение (в папку *build/*).
- `liblogger.so` — собрать только динамическую библиотеку.
- `check_style` — проверить стиль исходников с помощью `clang-format` (Google style).
- `docs` — сгенерировать документацию (в папку *docs/*).
- `open_docs` — открыть сгенерированную документацию.
- `test` — собрать и запустить тесты для библиотеки.
- `valgrind` — запустить тесты под Valgrind для обнаружения утечек.
- `coverage` — собрать тесты с покрытием кода библиотеки.
- `clean` — очистить временные и объектные файлы.
- `rebuild` — полностью пересобрать проект.
